# Ishwa Holidays - Premium Travel Portal

Ishwa Holidays is a world-class travel platform designed for high-end explorers. It features a stunning, cinematic landing page and a robust admin dashboard for managing leads, customers, and travel itineraries.

## 🌟 Key Features

- **Cinematic Landing Page**: Full-screen photo heroes, smooth scroll transitions, and a premium aesthetic.
- **Admin Dashboard**: Real-time management of travel leads and customer profiles.
- **Policy Alerts**: Automated system for tracking and notifying on policy expirations.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **Next.js 16/19 Stack**: Built with the latest React and Next.js features for maximum performance.

## 🛠️ Technology Stack

- **Framework**: Next.js (App Router)
- **Styling**: Tailwind CSS 4+
- **Database**: MongoDB with Mongoose
- **Animation**: Framer Motion
- **Icons**: Lucide React

## 🚀 Getting Started

1. **Clone the repository**
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Set up Environment Variables**:
   Copy `.env.example` to `.env` and fill in your credentials:
   - `MONGODB_URI`
   - `JWT_SECRET`
   - `ULTRAMSG_INSTANCE_ID`
   - `ULTRAMSG_TOKEN`
4. **Run the development server**:
   ```bash
   npm run dev
   ```

## 📦 Deployment

The project is optimized for deployment on **Vercel**:

1. Push your changes to GitHub/GitLab.
2. Connect your repository to Vercel.
3. Configure your Environment Variables in the Vercel dashboard.
4. Deploy!
